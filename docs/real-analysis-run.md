## 目的

验证「程序化分析」这条路能不能在不依赖模型描述的情况下给出可复核的结果。

## 数据

DepMap CRISPR 基因依赖性（CRISPRGeneEffect.csv）。

| 项 | 值 |
| --- | --- |
| 文件 | CRISPRGeneEffect.csv |
| 大小 | 约 430 MB |
| 基因 | 17,916 |
| 细胞系 | 1,183 |
| 来源 | DepMap Public（Broad Institute） |

## 结果

按选择性打分后，前三位：

| 排名 | 基因 | 说明 |
| --- | --- | --- |
| 1 | **SNRPD3** | 剪接体核心组分 |
| 2 | **CCND1** | 细胞周期 |
| 3 | **RAB10** | 小 GTP 酶 |

**泛必需性闸门通过**：所有候选在泛必需基因集合之外，说明不是普遍的细胞毒性。

## 这次运行证明了什么

- 430 MB 文件在合理时间内处理完，没有一次性读入内存
- 排序与筛选由程序执行，不是模型"读"出来的
- 泛必需性检查是硬编码的闸门，不是事后解释
- 产物落盘、按字节哈希登记

## 这次运行**没有**证明什么

- 生物学结论是否正确 —— 需要湿实验验证
- 方法是否最优 —— 没有和其他方法对比
- 结果是否可复现 —— 环境没有被钉死，`reproducible` 恒为 `false`

## 复现这次运行需要什么

1. 从 DepMap 下载同版本的 CRISPRGeneEffect.csv
2. 确认 pandas / numpy 可用
3. 用同样的选择性定义和泛必需基因集
