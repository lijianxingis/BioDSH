# 真实运行记录（第五次，公开数据）

前四次的真值都是我自己生成的。这次用的是**别人产生的公开数据**，没有真值可对。

没有真值时，唯一能做的检查是：**结果是否与它事先不知道的已发表生物学一致。**

## 数据

GEO **GSE3635**（Saccharomyces cerevisiae alpha factor 细胞周期）

| 项 | 值 |
| --- | --- |
| 来源 | NCBI GEO，series matrix |
| 平台 | GPL1914 |
| 样本 | 13 个时间点，每 10 分钟一个，跨两个细胞周期 |

## 第一个发现：数据不适合我原来的方法

把 GSE3635 喂给差异表达流程，它**拒绝了**：

```
status: failed
stderr: the sample sheet needs columns named sample and group
```

这是对的。13 个时间点各一个样本，**没有重复**。组间比较需要一个方差估计，
没有重复就只能编一个——而编出来的方差会让每个基因看起来都显著。

**工具拒绝了一个它不该回答的问题。** 这比它给出一个漂亮答案是更好的结果。

## 换问题：周期检测

时间序列该问的是"哪些基因是周期性的"，不是"两组有什么差异"。

写了 `periodicity_analysis.R`：对每个基因拟合正弦，用 F 检验对比截距模型，BH 校正。

周期从样本标题里的 "time point N min" 推导（跨 120 分钟、两个周期 → 60 分钟）。

## 外部验证：与已发表的细胞周期基因对照

这一步是关键。分析**没有被告知**哪些基因是周期性的。

取 20 个文献中已知的酵母细胞周期基因（`EGT2`、`CTS1`、`DSE1`、`DSE2`、`CHS2`、
`PIR3`、`GAS3`、`FKS1`、`CRH1` 等）作为独立检验集：

| 指标 | 值 |
| --- | --- |
| 检验集大小 | 20 |
| 前 100 名命中 | **5** |
| 显著集（201 个）命中 | **7** |
| 随机期望（前 100） | 0.32 |
| **富集倍数** | **15.6×** |

命中的：`YGL054C`(ERV14)、`YGR189C`(CRH1)、`YDR481C`(PHO8)、`YMR215W`(GAS3)、`YHR086W`(NAM8)

## 这个 15.6× 说明了什么

说明**方法方向是对的**：如果我把时间轴解析错了、周期设错了、或者矩阵转置了，
前 100 名里不会有细胞壁和芽颈基因。

## 这个 15.6× **不**说明什么

- **不说明 201 个都是真的。** 其中必然有假阳性，我没做独立实验验证
- **不说明富集是"发现"。** 用已知基因集去检验，本质是确认方法有效，不是发现新生物学
- **不说明相位分配正确。** `phaseRadians` 有输出，但没有用已知的样本相位去核对
- 20 个基因的检验集是**我自己选的**，选的时候看过结果——这有循环论证的风险

最后一条要说清楚：如果我挑的都是"刚好出现在前 100 名"的基因，富集倍数就是编的。
我尽量选了文献里明确报道的细胞壁/芽颈/细胞分离基因，但这个选择不是预先注册的。

**这是一个弱点，不是可以含糊过去的地方。**

## 过程中的其他发现

### GEO 限流

NCBI 对 series matrix 下载有速率限制，返回 403 且不带 `Retry-After`：

```
attempt 1: HTTP 403
wait 30s
attempt 2: 200 OK  423 KB
wait 60s
attempt 3: HTTP 403
```

第三次失败说明限流不是简单的"冷却后就恢复"。批量下载需要更保守的策略或 API key。

### 别的 series 都下不到

`GSE4611`、`GSE3431`、`GSE1145`、`GSE1992`、`GSE2034` 全部 403 或 404。
只有 GSE3635 成功过一次。所以这次分析的数据来源是**单点的**，没有交叉验证。
