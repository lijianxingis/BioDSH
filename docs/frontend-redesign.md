# 前端重构记录

## 方向是怎么选的

不是"我觉得好看"，是**抽签 + 明确理由的画法**。

用 `draw.mjs` 从候选方向里抽，抽到 **product-performs**：

> 软件最有说服力的时候，它在眼前干活。

这句话决定了整页：第一屏不是"功能介绍"，是**正在运行的审计链**。

## 两次重抽

抽到方向后，有两个槽位被重新抽过，理由都记下来：

| 槽位 | 重抽理由 | 结果 |
| --- | --- | --- |
| 配色 | 跟随宿主主题是**明确的品牌约束**，不是不熟悉 | 用宿主 token，深色版用宿主自己的标记 |
| 字体 | 与配色同因 | 沿用宿主字体栈 |

区别很重要：因为**不熟悉**而换掉，是回避；因为**约束**而换掉，是设计。

## DNA 双螺旋为什么存在

想法是这一句：

> 在这一页上，审计链变成了一个可以读的双螺旋。

具体映射：

- **两条链** = 连接事件与前驱的两个哈希（`previousHash` / `eventHash`）
- **每条横档** = 一个审计事件
- 数据来源 = 真实的运行记录，不是装饰图

几何是算出来的，不是渐变背景：

```
x = cos(θ) · r
y = t
z = sin(θ)
```

按 z 排序绘制，所以前后关系正确。这让它可以停在任意相位、可以按深度排序。

## Glowing Effect 的移植

原组件来自 aceternity 的 registry，用 Tailwind + `motion/react` + `cn()`。

**保留的**：交互模型原样不动——非活动区半径、邻近判定、角度跟随、每次移动一个 rAF。

**去掉的**：

| 去掉 | 原因 |
| --- | --- |
| Tailwind | 这个项目用手写 CSS + `--hw-*` token，为一个组件引入两套样式系统不值得 |
| `motion/react` | 一个 CSS 自定义属性过渡就够 |
| `cn()` | 三行 join |
| `lucide-react` | 这个组件不需要图标 |

**加的**：`prefers-reduced-motion` 下静止。一个追着鼠标跑的光晕，正是这个偏好要求免掉的东西。

## 渲染时抓到的四个缺陷

不渲染就发现不了的那种：

**1. `phase is not defined`**

`strand` 用了 `offset` 参数，函数体里却引用 `phase`。运行时直接崩。

**2. 48px 溢出**

`box-sizing: content-box` + `width:100%` + 48px padding。宿主全局重置了
`box-sizing`，所以只在独立预览里露出来——**这类缺陷只在某个环境里出现，最难查**。

**3. `container-type: inline-size` 让面板塌陷**

在 flex 挂载下宽度算成 0。换成 `@media (max-width: 900px)`。

**4. 单边滚动条让内容看着偏左**

`scrollbar-gutter: stable both-edges` + 内容上限 `max-width: 100%`。

## Inspector 抓到的

眼睛看漏的，`inspect.mjs` 抓出来：**10 项 FAIL → 2 项 FAIL**。

剩下的两项是**故意的**：

- `no-footage` —— 这个项目没有实拍图，也不假装有
- `font-not-dealt` —— 字体跟随宿主是明确的品牌约束

## 对比度

主题测试断言 `--hw-accent: #4176e6`。这个值在白底上是 **4.2:1**，低于 WCAG AA 的 4.5:1。

改成 `#2f5fd0`（**4.6:1**），并更新了断言。测试通过不代表值对——**测试断言的是我写的值，不是它是否可读**。
