## 恢复过程中重新抓到的缺陷

重写不是复制粘贴，所以有几个缺陷在重写时又出现了一次，被测试抓住：

1. **路径守卫对字符串简写无效。** `defineContract({ inputs: ['../escape.csv'] })` 被接受，
   因为字符串分支在守卫之前就 return 了。而模板用的正是这种简写。
2. **审计不覆盖 `bytes`。** 事件只记 path 和 digest，所以改掉记录的字节数后整链仍然验证通过。

两个都已修复并加了测试。
