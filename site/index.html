三件事不做

界面上不出现，是因为它们根本不存在。写着「研究用途」而不是「已认证」是有意的。

不声称可复现

reproducible 恒为 false。容器钉死工具链，没钉死算法。

不声称已认证

没有账号体系。签名是自签的，能证明持有某把密钥，不能证明是谁。

不声称临床可用

clinicalValidationStatus 恒为 required-not-performed。

装上就能跑

引擎是纯 Node，零外部依赖。不装 DSH 也能用。

# 不需要 DSH
git clone https://github.com/lijianxingis/BioDSH.git && cd BioDSH
npm install --ignore-scripts

node bin/dsh-research.mjs doctor        # 这台机器能干什么
node bin/dsh-research.mjs init ./work
node bin/dsh-research.mjs run sequence-analysis --workspace ./work
node bin/dsh-research.mjs verify <runId> --workspace ./work
node bin/dsh-research.mjs export <runId> --workspace ./work

status     : completed

这是研究原型，不是临床工具。没有合规认证，没有真实用户，没有临床验证。
